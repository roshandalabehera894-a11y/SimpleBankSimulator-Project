# 🏦 Simple Bank Simulator

A beginner-friendly console-based banking application built with Java to simulate basic bank account operations.

---

## ✨ Features

- **Deposit**: Add money to your account with amount validation.
- **Check Balance**: View your current available balance at any time.
- **Withdraw**: Take out funds with checks to prevent overdrawing.
- **Account Management**: Create and manage basic account details.
